# Sound Files Guide

This directory should contain audio files for game sound effects and background music.

## Required Sound Files:

### Card Sounds:
- **card-flip.mp3** - Sound when flipping cards
- **card-deal.mp3** - Sound when dealing cards  
- **shuffle.mp3** - Sound when shuffling deck

### UI Sounds:
- **button-click.mp3** - Button press sound
- **button-hover.mp3** - Button hover sound (optional)
- **notification.mp3** - General notification sound

### Game Sounds:
- **game-start.mp3** - Game starting sound (optional)
- **victory.mp3** - Game won sound
- **defeat.mp3** - Game lost sound (optional)
- **match.mp3** - Successful match in memory game
- **no-match.mp3** - Failed match in memory game
- **error.mp3** - Error sound

### Background Music (Optional):
- **menu-music.mp3** - Background music for main menu
- **gameplay-music.mp3** - Background music during games
- **victory-music.mp3** - Victory celebration music

## Audio Specifications:
- **Format**: MP3 (best compatibility) or OGG
- **Quality**: 128kbps or higher
- **Length**: Keep sound effects under 2 seconds
- **Volume**: Normalize all files to similar volume levels
- **Size**: Keep files small for web delivery

## Free Sound Resources:
- **Freesound.org** - Community sound library
- **Zapsplat** - Professional sound effects
- **AudioJungle** - Premium sounds (paid)
- **OpenGameArt.org** - Game-specific sounds

## Notes:
- All sound files are optional - the game will work without them
- The application will automatically detect and use available sounds
- Sounds enhance the user experience but aren't required for functionality
- Consider browser autoplay policies when implementing background music
