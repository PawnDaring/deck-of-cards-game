# Deck of Cards Game Collection

A scalable web-based card game application featuring multiple classic card games using a standard 52-card deck.

## 🎮 Games Included

### 1. Go Fish
- **Players:** 2-4 players
- **Objective:** Collect the most sets of four cards of the same rank
- **Features:** 
  - AI opponents with adjustable difficulty
  - Real-time multiplayer support
  - Turn-based gameplay with animations

### 2. War
- **Players:** 2 players
- **Objective:** Capture all cards by winning battles
- **Features:**
  - Single player vs AI
  - Multiplayer mode
  - War resolution animations
  - Game statistics tracking

### 3. Matching Game (Memory)
- **Players:** 1-4 players
- **Objective:** Find matching pairs of cards
- **Features:**
  - Multiple difficulty levels (grid sizes)
  - Timer and move counter
  - Leaderboard system
  - Custom card themes

## 🏗️ Architecture & Scalability

### Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Framework:** Vanilla JS with modular design
- **Styling:** CSS Grid/Flexbox with custom properties
- **Assets:** SVG/PNG card images with lazy loading
- **Storage:** LocalStorage for game state and preferences

### Modular Design
```
src/
├── core/           # Core game engine
│   ├── Card.js     # Card class and utilities
│   ├── Deck.js     # Deck management
│   ├── Player.js   # Player management
│   └── GameEngine.js # Base game logic
├── games/          # Individual game implementations
│   ├── GoFish.js   # Go Fish game logic
│   ├── War.js      # War game logic
│   └── Memory.js   # Matching game logic
├── ui/             # User interface components
│   ├── GameUI.js   # Base UI class
│   ├── CardRenderer.js # Card rendering
│   └── AnimationEngine.js # Animations
└── utils/          # Utility functions
    ├── EventManager.js # Event handling
    ├── SoundManager.js # Audio management
    └── StorageManager.js # Data persistence
```

## 🎯 Getting Started

### Prerequisites
- Modern web browser (Chrome 90+, Firefox 88+, Safari 14+)

2. Place your card images in the `assets/cards/` directory

```bash
npx serve .

# Or use VS Code Live Server extension
```

## 🎮 Game Rules

### Go Fish
1. Each player starts with 7 cards (6 if 4+ players)
2. Players ask others for cards of specific ranks
3. If opponent doesn't have the rank, they say "Go Fish"
4. First to collect 4 sets wins

### War
1. Deal entire deck equally between players
2. Each player plays their top card
3. Highest card wins both cards
4. Ties trigger "war" - 3 cards down, 1 up
5. Winner takes all cards in play

### Matching Game
1. Cards are placed face-down in a grid
2. Players take turns flipping 2 cards
3. If cards match, player keeps them and goes again
4. If no match, cards flip back over
5. Player with most pairs wins
